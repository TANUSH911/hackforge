# Practice 01 — Civic Tech (mock 24h hackathon)

**Format:** 24 hours, in person, solo allowed. Mock event for testing HackForge.

## Problem statement
**"Fixing the last mile of civic complaints."**
Citizens in Bengaluru report potholes, garbage black spots, broken streetlights and water leaks through apps, Twitter and helplines, but many complaints are duplicated, routed to the wrong department, or closed without being fixed. Build a solution that helps citizens and/or city officials get civic issues reported, routed and actually resolved faster.

## Judging criteria
| Criterion | Weight |
|---|---|
| Innovation and originality | 25% |
| Technical implementation (working demo) | 25% |
| Real-world impact and feasibility | 25% |
| Design and user experience | 15% |
| Presentation | 10% |

## Rules
- All code written during the event (open-source libraries and APIs allowed).
- Must have a working demo; slides alone score zero on technical.
- Submission: GitHub repo, 2-minute demo video, 5-slide deck.

## Sponsor tracks
- **Best use of AI** — any LLM or vision model.
- **Best use of open government data**

## Builder constraints
Solo developer, intermediate Python/Java/C, ₹0 budget, 8 GB Intel MacBook.
