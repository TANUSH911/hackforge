# Pitch playbook — 2-minute demo and 5-slide deck

## The 2-minute structure
| Time | Beat | What to say/do |
|---|---|---|
| 0:00–0:15 | **Hook** | One human sentence + one number. "Ravi reported this pothole 15 times. It was marked fixed 15 times." |
| 0:15–0:30 | **Solution** | Product name + one sentence. Product already on screen. |
| 0:30–1:20 | **Demo** | Walk the persona through the core flow. Wow moment by 0:45. Narrate the *user's* experience, not the code. |
| 1:20–1:40 | **How** | One diagram, 3–5 boxes. Name the hard part and the AI part honestly. |
| 1:40–2:00 | **Impact** | Who it helps, the number it moves, what's next. End on the product name. |

## The 5 slides (max 25 words each)
1. **Problem** — one striking, sourced number + who suffers.
2. **Solution** — name, one sentence, one screenshot of the wow screen.
3. **Demo** — (switch to live app or video).
4. **How it works** — simple diagram, stack logos, what's AI vs rules.
5. **Impact & next** — measurable impact, 2–3 next steps, team/contact.

## Demo-day rules
- **Rehearse 3 times with a timer.** Cut words, not the wow.
- **Record a backup video** at hour 20 while everything works. If live fails, switch without apologising at length.
- **Pre-open every tab** (app on the right screen, `/health` checked, backup video ready). Close notifications.
- **Use the demo records** from the seed data, never live-typed random input.
- **Mobile app?** Mirror the phone or use browser device mode; text must be readable from the back.
- **One person drives, one person talks** (solo: practise talking while clicking).

## Demo video (2 min) recording tips
- Screen at 1920×1080, browser zoom 125%, hide bookmarks bar.
- Record voice separately if the room is noisy; captions for key lines.
- Start on the hook, not on a title card. End on the product name + URL.
- Free tools: OBS Studio or macOS QuickTime screen recording; trim in iMovie/Clipchamp.

## Answering judge questions
- Answer in 2 sentences, then stop.
- If you don't know: "We haven't measured that yet; here's how we would."
- If it's demo data: say so first, then say where real data comes from.

## Devpost / submission checklist
Tagline (<60 chars) · inspiration · what it does · how we built it · challenges · accomplishments · what we learned · what's next · built-with tags · demo video link · GitHub link · live URL · screenshots (3–5, wow screen first). Submit **1 hour early**.
